# Array Functions

The following functions are array functions in the FX class.

## Functions

- [extendArray](#extendArray)

## extendArray

### Description

`extendArray(array ...$arrays)`

Extends the arrays by merging them together. If arrays have duplicate keys then they will replace but if the arrays have no defined key they will merge.

### Parameters

**arrays**
: Variable list of arrays to merge.

### Return Value

Returns the merged array.
